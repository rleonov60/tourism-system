# Информационная система туристической фирмы «Горизонт»

## О проекте
Веб-приложение для управления туристической фирмой. Включает в себя админ-панель (управление турами, клиентами, путёвками, платежами) и систему безопасности (2FA, капча-пазл, блокировка при подборе пароля).

## Стек технологий
- **Серверная часть:** PHP 8+
- **База данных:** MariaDB (MySQL)
- **Клиентская часть:** HTML5, CSS3, JavaScript
- **Локальный сервер:** XAMPP

## Как развернуть проект на другом компьютере

### 1. Установите XAMPP
Скачайте и установите [XAMPP](https://www.apachefriends.org/). Запустите **Apache** и **MySQL**.

### 2. Скопируйте проект
Скачайте этот репозиторий и поместите папку `api` в директорию `C:\xampp\htdocs\` (или `htdocs` на вашем диске).

### 3. Импортируйте базу данных
1. Откройте в браузере `http://localhost/phpmyadmin`.
2. Создайте базу данных `tourism_db`.
3. Перейдите на вкладку **Импорт**, выберите файл **`database.sql`** из этого репозитория и нажмите «Вперед».

### 4. Настройте подключение (если нужно)
Если у вас пароль от базы данных не пустой, откройте файлы `ui.php`, `login.php`, `print_contract.php` и замените:
`new mysqli("localhost", "root", "", "tourism_db");`
на:
`new mysqli("localhost", "root", "ВАШ_ПАРОЛЬ", "tourism_db");`

### 5. Запустите
Откройте в браузере: **`http://localhost/api/login.php`**
